# Level 17 Comparing files content

## Overview

Level 17 required comparing two different files to identify differences in content.
This could be achieved by using the diff command.

While the uniq command is also used to match unique/duplicate patterns, it can only do it for a single file.

## Walkthrough

<details>
<summary>Spoiler</summary>

Use SSH to login to the server. Compare the file content using the diff command.

</details>

## Commands

<details>
<summary>Spoiler</summary>
