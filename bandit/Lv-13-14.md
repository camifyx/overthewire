# Level Guide

## Hint

OverTheWire prevents logging in from one level to another. Log out first.

## Walkthrough

Public key: `/etc/bandit_pass/bandit14`
Private key: `/home/bandit13/sshkey.private`

I copied the private key to my local machine with scp, then attempted to SSH into bandit14 with it. The connection was refused because the key's permissions were too open — chmod 400 fixed that. A second attempt succeeded.

## Commands

<details>
<summary>Spoiler</summary>
  
| Command | Purpose |
|---|---|
| `scp -P 2220 bandit13@bandit.overthewire.org:'~/sshkey.private' ~/sshkey.private` | Copy the private key to your local machine |
| `chmod 400 ~/sshkey.private` | Restrict permissions (required by SSH) |
| `ssh -i ~/sshkey.private -p 2220 bandit14@bandit.overthewire.org` | Log in with the key. Use the '-i' flag to indicate the file.|

</details>
