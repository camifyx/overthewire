# Level Guide

## Hint

The password for the next level can be retrieved by submitting the password of the current level to port 30000 on localhost.

## Walkgrough

<details>
<summary>Spoiler</summary>

**Password location**: `/etc/bandit_pass/bandit14`
**File owner**: bandit14

The password for level 15 can only be retrieved by bandit14 itself, at the path above. SSH into bandit14 normally, then connect to a local service on port 30000

</details>

## Commands

<details>
<summary>Spoiler</summary>

|**Command**|**Purpose**|
|---|---|
|`ssh -p 2220 bandit14@bandit.overthewire.org`|Log in as bandit14|
|`telnet localhost 30000`|Connect to the localhost with port 3000|

</details>
