### Walkthrough

`data.txt` is actually a hexdump of a file that was compressed multiple times.
The first step is to inspect the raw bytes and identify the file format.

```bash
xxd data.txt | head
```

This shows the hexadecimal dump. The first bytes (`1f 8b`) indicate a gzip-compressed file, which confirms that the content is compressed.

Next, convert the hexdump back into binary:

```bash
xxd -r data.txt > data
file data
```

Now that the file is restored, inspect it again and determine the compression format. In many cases, you will need to repeatedly decompress the file until you reach the final plaintext content.

Typical sequence:

```bash
file data
gzip -d data
file data
bzip2 -d data.bz2
file data
tar -xf data.tar
```

Repeat this process until the file is no longer compressed. Once you have the final file, read it and extract the password for the next level.
